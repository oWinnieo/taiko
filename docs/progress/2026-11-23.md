## 2. 关键决策
- **素材清理**：对 `Better-taiko-web` 资源逐一做 PNG 像素与音频波形校验，剔除 34 个全透明空 PNG、1 个空 GIF、1 个空 `vectors.json` 及 14 个静音音频，仅保留 194 个真实有效资源（9.5 MB）。
- **技术栈**：采用 `Vite 6 + TypeScript 5 + React 19` + 纯 TS `Canvas 2D` 演奏渲染引擎 + `Web Audio API`（内置 `@wasm-audio-decoders/ogg-vorbis` 兜底，兼容 Safari 与未来 macOS Tauri WKWebView）。
- **适度可扩展设计**：
  - 平台存储经由 `PlatformAdapter` 隔离（Web 端为 IndexedDB + localStorage，后续 Tauri 2.0 桌面端仅需新增原生文件适配器）。
  - 谱面经由结构化 `ChartDocument` AST + `parseTja` / `serializeTja` 双向实现，为后续谱面编辑器预留基础。
  - 支持内置曲目清单扩展 + 页面拖入本地 `.tja` 与音频文件游玩。
